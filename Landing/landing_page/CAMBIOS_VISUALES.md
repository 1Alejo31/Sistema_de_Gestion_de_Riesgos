## ✨ TIPOS DE ANIMACIONES

### 1. **Fade + Translate** (Entrada)
```
Elemento aparece:
Opacity: 0 → 1
Y position: +30px → 0px
Duración: 400-1400ms
Curve: easeOut
```

### 2. **Floating** (Continua)
```
Cards flotan:
Y position: 0px → ±20px → 0px
Duración: 3 segundos
Loop: infinito
Curve: easeInOut
```

### 3. **Glow Pulse** (Continua)
```
Icono pulsa:
Shadow opacity: 0.2 → 0.4 → 0.2
Duración: 2 segundos
Loop: infinito
```

### 4. **Hover Elevation**
```
Card en hover:
Y position: 0 → -8px
Shadow blur: 16px → 32px
Border opacity: 0.2 → 0.5
Duración: 300ms
Curve: easeOut
```

### 5. **Scale Animation**
```
Estadísticas aparecen:
Scale: 0.8 → 1.0
Opacity: 0 → 1
Stagger delay: 200ms
Duración: 1500ms
Curve: easeOutCubic
```
